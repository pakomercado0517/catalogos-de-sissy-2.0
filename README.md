# Catálogos de Sissy 2.0 📱

[![Deployment](https://img.shields.io/badge/deployment-vercel-black)](https://catalogos-de-sissy.vercel.app)
[![React](https://img.shields.io/badge/react-18.3.1-blue)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/vite-4.5.3-purple)](https://vitejs.dev/)
[![TailwindCSS](https://img.shields.io/badge/tailwindcss-3.4.10-blue)](https://tailwindcss.com/)

Una aplicación web moderna para explorar y cotizar productos de diferentes catálogos de moda y accesorios.

## 🌟 Características

- 🔍 Búsqueda inteligente de productos con IA
- 📱 Interfaz responsive y moderna
- 🛍️ Exploración de múltiples catálogos
- 💬 Chat asistente para ayuda personalizada
- 📞 Sistema de cotizaciones directo
- 🎨 Diseño moderno con Tailwind CSS

## 🚀 Tecnologías

- **Frontend:** React 18
- **Build Tool:** Vite
- **Estilos:** Tailwind CSS
- **UI Components:** Flowbite React
- **State Management:** Redux + Redux Toolkit
- **Routing:** React Router DOM
- **AI Integration:** OpenAI
- **Web Scraping:** Puppeteer
- **Animaciones:** TailwindCSS Animated

## 📦 Instalación

1. Clona el repositorio:

   ```bash
   git clone https://github.com/pakomercado0517/catalogos-de-sissy-2.0.git
   ```

2. Instala las dependencias:

   ```bash
   pnpm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   pnpm dev
   ```

## 🛠️ Scripts Disponibles

- `pnpm dev` - Inicia el servidor de desarrollo
- `pnpm build` - Crea la build de producción
- `pnpm lint` - Ejecuta el linter
- `pnpm preview` - Previsualiza la build de producción
